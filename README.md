# 股市情勢

台股大盤情勢燈號、個股趨勢判斷（技術面＋三大法人與融資籌碼＋K 線＋月營收）、基本面、市場新聞、強弱勢與法人買賣超排行。純靜態網頁，資料由 GitHub Actions 每個交易日盤後從證交所與櫃買中心累積。

## 第一次設定

1. **開啟 GitHub Pages**：Settings → Pages → Build and deployment → Source 選「Deploy from a branch」，Branch 選 `main`、資料夾 `/ (root)`，Save。
2. **跑第一次資料**：Actions → 左邊選「收盤價歷史」→ Run workflow。第一次會往回補 120 個交易日的行情與 60 個交易日的法人、融資，要幾十分鐘；一次跑不完會分幾次，跑完自動提交 `history.json`、`d/`、`news.json`。
3. 之後每個交易日台北 15:05 與 17:40 會自動更新，不用再管。

網址是 `https://<帳號>.github.io/<repo 名稱>/`。

## 檔案

- `index.html`：整個網站，沒有外部函式庫。儀表板式版面：總覽首頁、個股分析、排行榜、法人動向、自選股、新聞快訊六個頁面，左側選單切換。
- `scripts/fetch_history.py`：抓上市與上櫃每日全市場的開高低收、成交量、三大法人買賣超、融資融券餘額，加上本益比、殖利率、月營收、EPS 的快照與 Google 新聞 RSS。全市場精簡版寫進 `history.json`，每檔詳細版依代號分片寫進 `d/`。
- `.github/workflows/history.yml`：排程。

## 判斷怎麼算

大盤與個股用同一套機械式計分（-11 ～ +11），逐條列在頁面上：均線排列（±2）、月線方向、近 20 日動能、RSI（14）、MACD 柱、60 日區間位置、K 線型態、外資 5／20 日方向、投信 5 日方向、月營收年增率各 ±1；量能與融資變化只做備註。大盤再加上站上月線／季線的個股比例、新高新低家數、外資與投信 5 日買賣超金額。只是幫你看清楚位置，不是投資建議。
